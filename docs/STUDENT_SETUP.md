# Additional student setup help

The root [`README.md`](../README.md) is the single canonical start-to-finish
student walkthrough. Follow it first.

This page only provides extra help for installing tools, opening the project,
and resolving common setup problems. It intentionally does not repeat the full
OpenEMR import workflow.

> All records generated by this project are synthetic. Never represent them as
> real patient information.

## Clone with GitHub Desktop

The repository is public:

<https://github.com/CabbageCanFly/maple-grove-synthea-openemr>

In GitHub Desktop:

1. Select **File -> Clone repository**.
2. Select the **URL** tab.
3. Enter:

   ```text
   https://github.com/CabbageCanFly/maple-grove-synthea-openemr.git
   ```

4. Choose a local folder you can find easily.
5. Select **Clone**.

GitHub Desktop downloads and updates the project, but Synthea and importer
commands still run in WSL or macOS Terminal.

## Open the cloned project in WSL

In Windows File Explorer:

1. Open the cloned repository folder.
2. Click the address bar.
3. Type:

   ```text
   wsl
   ```

4. Press **Enter**.

Confirm the terminal is in the repository root:

```bash
test -f README.md && test -d scripts && echo "Project folder detected."
```

## Open the cloned project on macOS

In GitHub Desktop, select:

```text
Repository -> Open in Terminal
```

Alternatively, open Terminal, type `cd ` with a trailing space, drag the
repository folder into the Terminal window, and press **Enter**.

## Install Python and Java in WSL

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip openjdk-17-jdk
```

Verify:

```bash
python3 --version
java -version
```

Python must be 3.10 or newer. Java should report version 17.

## Install Python and Java on macOS

With Homebrew:

```bash
brew install python
brew install --cask temurin@17
```

Verify:

```bash
python3 --version
java -version
```

## Docker is only required for local OpenEMR

Students using a shared AWS OpenEMR server do not need Docker Desktop.

Students using local OpenEMR need Docker Desktop running before the README's
local OpenEMR preparation step.

## Python environment problems

Create the environment from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements_openemr_import.txt
```

If `python3 -m venv` reports that `venv` is unavailable in WSL:

```bash
sudo apt update
sudo apt install -y python3-venv
```

If the terminal does not show `(.venv)`, activate it again:

```bash
source .venv/bin/activate
```

## Synthea JAR problems

Download the exact project release:

```bash
mkdir -p dist

curl -L \
  https://github.com/CabbageCanFly/maple-grove-synthea-openemr/releases/download/v0.1.1/synthea-gta-maple-grove-v0.1.1.jar \
  -o dist/synthea-gta-maple-grove-v0.1.1.jar
```

Confirm that the file is not empty:

```bash
ls -lh dist/synthea-gta-maple-grove-v0.1.1.jar
```

If the generator says no GTA Synthea JAR was found, make sure the file is under
this repository's `dist/` directory and that its name ends in `.jar`.

## Terminal-session login problems

At the beginning of an OpenEMR terminal session, run:

```bash
source scripts/openemr_session.sh
```

The word `source` is required. Running the file as
`./scripts/openemr_session.sh` cannot update the current terminal environment.

If the username or password was entered incorrectly, run the same `source`
command again and re-enter the login.

To remove the login from the current terminal:

```bash
openemr_logout
```

## Receiving project updates

In GitHub Desktop:

1. Open this repository.
2. Select **Fetch origin**.
3. Select **Pull origin** when updates are available.

Before pulling, save or commit any local code/document changes you want to keep.
Generated data, `.local/`, `.venv/`, and downloaded JAR files are intentionally
not shared through Git.
